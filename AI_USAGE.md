# AI_USAGE.md — AI usage log for the TSS lab deliverable (`tss/lab`)

Required format per the assignment: **tool · purpose · prompt/request ·
result · team edits · verification/validation**, defensible at presentation.
This file logs every significant use of AI tooling that contributed to the
deliverables in `tss/lab` (SPEC, the four test suites + derivation docs, the
CFG artifacts, the manual mutants + demo, and the two-tool mutation analysis).

**Honest scope statement.** This lab was produced *with* an AI coding agent
under team direction: a ZCode CLI agent (GLM model) driving the local Python
3.14.6 / pytest 8.4.2 toolchain on Windows. The agent ported the module,
wrote the specification and all suites/docs, and executed every verification
run whose receipts are cited below. No other AI tools (ChatGPT, Copilot,
Gemini, …) were used. The team set the scope, reviewed every artifact, and is
responsible for its content — including the parts generated by the agent.
The module under test itself (`pricing.py`) is the team's own pre-existing
code from the `momentstudio` repository, written before this lab; it was
**not** AI-generated for this assignment.
